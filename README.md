# Codex 限额悬浮窗

一个本地、无遥测的 Windows 小组件，用于同时显示 Codex 5 小时额度、每周额度、各自重置时间和“完全重置”到期时间。

主界面以较大的数字显示主额度，另一项额度在下方显示。自动模式会识别接口返回的套餐：Pro（含 prolite）以每周额度为主，并隐藏 5 小时行；其他账户有 5 小时额度时优先显示它，否则以每周额度为主。也可以在托盘菜单手动选择显示模式。

## 功能

- EXE 与快捷方式使用原创水位 Q 图标，内置 16–256 像素多分辨率；托盘和任务栏保留动态额度数字
- 默认以水位悬浮球常驻：大号纯数字表示剩余百分比（省略 %），水位随剩余额度升降
- 浅色与深色主题均覆盖悬浮球和详情面板；支持手动选择或按时间自动切换
- 默认 07:00 切为浅色、18:00 切为深色，采用本机时间；可修改时间，跨午夜也支持
- 主题颜色采用约半秒平滑渐变，包含背景、边线、水位和数字颜色
- 悬浮球大小可在 48–160 像素之间调节，滑块实时预览，数字和水位同比缩放，保存后记住设置
- 展开面板大小可独立在 75%–150% 之间缩放，文字、布局和按钮点击区域同比缩放，支持实时预览及保存
- 检测到 Pro 或手动选择 Pro 时，隐藏 5 小时额度行并收紧面板高度，托盘提示也省略这一项
- 水位轻微波动有独立开关，关闭后水面平直，仍可保留主题与水位的平滑过渡
- 单击圆球展开大字详情面板，点击右上角减号收回；支持拖动，展开时自动避开屏幕边缘
- 悬浮球和详情面板均可右键设置；支持关闭水波动效，隐藏时暂停绘制
- 连接失败时保留上次成功数据并标明状态，悬停可查看完整错误
- 桌面悬浮窗，可拖动、置顶、切换紧凑模式和不透明度
- 自动、Plus（5 小时优先）、Pro（每周优先）三种显示模式；缺少首选额度时自动回退到另一项
- 主额度的剩余百分比、进度条与重置时间；另一项额度在下方显示
- 下次重置日期与时间采用更大字号，保持比额度数字更低的视觉权重；支持左右镜像布局
- 常驻水波约 25 帧/秒，渐变时按需提高帧率；复用字体、水波路径、点数组及画刷，静态或隐藏时停止动画计时器
- 通过事件唤醒已有窗口，不再持续轮询；百分比不变时复用托盘图标，退出时取消正在进行的额度读取
- 系统托盘常驻，图标显示主额度百分比
- 可选任务栏主额度百分比图标
- 当前用户开机启动
- 主额度低于 10%、20% 或 30% 时通知，每个重置周期只提醒一次
- 15 秒、1 分钟或 5 分钟自动刷新，支持手动刷新
- 显示“完全重置”次数及到期时间；接口未提供时可手动录入
- 隐藏后再次运行 EXE，可唤醒现有窗口而不会重复启动
- 不读取、复制或保存 `auth.json`、浏览器 Cookie、密码或 API Key

## 环境要求

- Windows 10 或 Windows 11，64 位（x64）
- [Microsoft .NET 9 Desktop Runtime x64](https://dotnet.microsoft.com/download/dotnet/9.0/runtime)
- 已安装并登录 ChatGPT 账户的 Codex Desktop 或 Codex CLI
- Codex 安装需要支持本机 `app-server` 接口
- 读取最新账户限额时需要网络连接

请安装下载页面中的 **.NET Desktop Runtime**，不要只安装普通的 `.NET Runtime`。如果运行 EXE 时提示缺少 `Microsoft.WindowsDesktop.App 9.0`，说明 Desktop Runtime 尚未安装或架构不匹配。

## 安装

1. 构建或下载最新的 `CodexQuotaWidget-v3.x.x-framework-dependent-win-x64.zip`。
2. 对照同一 Release 中的 `SHA256SUMS.txt` 校验下载文件。
3. 解压到固定目录，不要直接在 ZIP 内运行。
4. 双击 `CodexQuotaWidget.exe`。
5. 如需开机运行，右键托盘百分比图标并启用“开机启动”。

程序当前没有商业代码签名，因此 Windows SmartScreen 可能显示“未知发布者”。请只从本仓库的 Release 页面下载并核对 SHA-256。

## 使用

- 拖动悬浮窗可改变位置。
- 单击悬浮球展开面板，点击左上角 `CODEX` 或右上角 `−` 收回悬浮球。
- 点击右上角 `↻` 或选择右键菜单“立即刷新”可手动刷新。
- 在悬浮球、面板或托盘上右键选择“隐藏到托盘”可隐藏。
- 右键“悬浮球大小…”打开大小滑块；保存会记住大小，取消则恢复原大小。
- 右键“展开面板大小…”调整面板缩放；两种形态分别记住大小，取消可恢复。
- 右键“主额度位置”选择靠左或靠右；下次重置日期、时间以放大的浅色文字显示在额度数字旁边，跟随布局镜像排列，保存后下次启动仍保留。
- “水位轻微波动”和“平滑过渡（主题与水位）”是两个独立开关，均在右键菜单中。
- 在“外观主题”中选择浅色或深色会关闭自动切换；勾选“按时间自动切换”可恢复自动模式。
- “设置切换时间…”可修改浅色和深色的开始时间。关闭自动切换会保留当时的主题；隐藏期间不播放动画。
- 窗口获得焦点时，Enter / 空格切换形态，Esc 收回，R 刷新。
- 双击托盘图标或再次运行 EXE 会恢复已有窗口。
- 需要完全关闭时，请右键托盘图标并选择“退出”。
- 右键托盘图标，在“额度显示模式”中选择“自动”“Plus：5 小时优先”或“Pro：每周优先”。这个选项仅控制显示优先级，不会更改实际订阅或额度。

程序通过 Codex 本机 `app-server` 的只读 `account/rateLimits/read` 方法获取额度，并分别识别 300 分钟与 10080 分钟窗口。配置保存在 `%LOCALAPPDATA%\CodexQuotaWidget5hWeekly\settings.json`，单实例标识和开机启动项也与旧版分离，因此两个版本可以同时运行。

## 显示规则

- 检测到 Pro（套餐标识以 pro 开头）或手动选择 Pro：仅显示每周额度，隐藏 5 小时行并收紧高度
- 其他账户自动 / Plus 模式：优先显示 5 小时额度，未返回时回退到每周额度
- 托盘、任务栏图标和低额度提醒均跟随主额度
- 未返回的次要额度标为“未提供”，不会伪造数字

## 隐私与安全

- 没有遥测、广告或自动更新服务。
- 不读取 `auth.json`，不收集浏览器 Cookie，不内置账户令牌。
- 额度请求由已安装的 Codex 进程完成，应用只读取返回的限额数据。
- 不包含用户配置、额度数据、账户 ID、用户名或构建电脑绝对路径。
- 开机启动只写入当前用户的 Windows `Run` 注册表项。

## 本地构建

需要 .NET 9 SDK：

```powershell
.\build.ps1 -Runtime win-x64
```

或者：

```powershell
dotnet publish .\CodexQuotaWidget\CodexQuotaWidget.csproj -c Release -r win-x64 --self-contained false
```

输出位于 `artifacts\win-x64`。使用 `--demo` 参数可以在无 Codex 数据源时查看界面。
