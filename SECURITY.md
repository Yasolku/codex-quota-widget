# Security

Codex Quota Widget is a local-only desktop utility. It launches the installed
Codex `app-server` and requests the read-only `account/rateLimits/read` method.
It does not read or store browser cookies, passwords, API keys, or Codex
authentication files, and it contains no telemetry.

Please report security issues privately to the repository maintainer rather
than publishing account data, logs, screenshots, or authentication material in
a public issue.
