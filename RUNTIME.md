# Runtime requirement

Codex Quota Widget v3.5.1 requires **Microsoft .NET 9 Desktop Runtime**.

- Operating system: Windows 10 or Windows 11
- Architecture: x64 for the `win-x64` Release asset
- Official download: https://dotnet.microsoft.com/download/dotnet/9.0/runtime

Install **.NET Desktop Runtime**, not only the standard .NET Runtime. A missing-runtime message mentioning `Microsoft.WindowsDesktop.App 9.0` means the Desktop Runtime is absent or the wrong architecture was installed.
